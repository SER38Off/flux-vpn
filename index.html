Подробный гайд по настройке

🍎

Настройка для iOS (iPhone / iPad)

  • Установите приложение Happ из App Store по кнопке в самом верху сайта.
  • Вернитесь на наш сайт и выберите подходящую подписку. Нажмите синюю кнопку «Добавить в Happ».
  • Приложение откроется автоматически. Нажмите Save / Import (Сохранить).
  • Если кнопка не сработала: нажмите Скопировать. Затем в Happ перейдите в Profiles (Профили) ➔ Add (Плюс) ➔ Import from URL и вставьте ссылку.
  • Разрешите добавление VPN-конфигурации в настройках iPhone (это стандартная защита Apple).
  • На главном экране выберите сервер с самым низким пингом и нажмите большую кнопку включения.
🤖

Настройка для Android

  • Загрузите Happ из Google Play.
  • На нашем сайте нажмите «Добавить в Happ» рядом с нужной подпиской.
  • Если не перекидывает, скопируйте ссылку. В приложении Happ откройте меню Подписки ➔ Нажмите ➕ ➔ Импорт по ссылке. Вставьте ссылку и сохраните.
  • Важно: Нажмите значок Обновить 🔄 (круговые стрелки) в правом верхнем углу, чтобы приложение скачало список свежих серверов.
  • Зайдите в ⚙️ Настройки ➔ Пинг (Ping) ➔ выберите TCP для точного замера скорости.
  • Выберите сервер из списка и подключайтесь!
💻

Настройка для ПК (Windows, macOS, Linux)

  • Скачайте и установите десктопную версию Happ.
  • Скопируйте любую подписку с нашего сайта (кнопка Скопировать).
  • Откройте Happ на компьютере ➔ перейдите в раздел Subscriptions (или Profiles / Servers).
  • Нажмите Add (Добавить) и вставьте вашу ссылку. Сохраните.
  • Обязательно нажмите Update (Обновить), чтобы подтянуть сервера из интернета.
  • Выберите сервер с минимальным пингом и нажмите Connect.
📺

Настройка для Android TV

  • Найдите приложение Happ во встроенном магазине телевизора (или установите через APK).
  • Скопируйте ссылку на подписку с телефона и отправьте её себе в «Избранное» Telegram или любой мессенджер.
  • Откройте Happ на телевизоре ➔ зайдите в Subscriptions ➔ Add from URL.
  • Введите скопированную ссылку. (Совет: используйте приложение Android TV Remote на смартфоне, чтобы вставить текст как с клавиатуры).
  • Сохраните, нажмите кнопку обновления списка серверов и подключайтесь.
