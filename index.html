📖 Инструкции по подключению

📱 Android

  • Открой Happ и перейди в Подписки
  • Нажми ➕ Добавить -> По ссылке
  • Вставь скопированную ссылку подписки
  • Нажми Сохранить и включи VPN ✅

🍎 iOS (iPhone / iPad)

  • Перейди в Profiles / Subscriptions
  • Нажми Add -> Import from URL
  • Вставь ссылку и подтверди добавление
  • Разреши VPN в системе (это безопасно)
  • Включи VPN в приложении ✅

💻 ПК (Windows/macOS/Linux)

  • Запусти Happ -> Profiles / Subscriptions
  • Нажми Add
  • Вставь ссылку и сохрани
  • Выбери сервер и нажми Connect ✅

📺 Android TV

  • Зайди в Subscriptions / Profiles
  • Нажми Add -> From URL
  • Вставь ссылку (используй Google Keyboard с телефона)
  • Сохрани и включи VPN ✅

🔁 Если VPN перестал работать:

  • Нажми кнопку Обновить подписку / Update 🔄 в приложении.
  • Если не помогло — удали старую подписку и добавь новую с этого сайта.
  • Перезапусти приложение.
