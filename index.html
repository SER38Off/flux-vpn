Умная подписка [Автообновление]

В этой подписке встроено автоматическое обновление серверов. Если РКН блокирует текущие серверы, подписка сама переходит на рабочие резервы. Ваш VPN будет работать стабильно — достаточно просто нажать на кнопку обновления 🔄 в приложении.

Ссылка на конфигурацию:

https://raw.githubusercontent.com/igareck/vpn-configs-for-russia/refs/heads/main/Vless-Reality-White-Lists-Rus-Mobile.txt

Совет: После добавления подписки нажмите на значок «спидометра». Выберите сервер, где пинг (мс) меньше — там скорость лучше. Если написано н/а или н/д, этот сервер сейчас недоступен.

Инструкции по настройке (Happ)

📱 Android (телефон / планшет)

  • Открой Happ
  • Перейди в Подписки или Профили
  • Нажми ➕ Добавить -> Выбери Добавить по ссылке
  • Вставь ссылку подписки (из блока выше) и нажми Сохранить
  • Вернись на главный экран и включи VPN ✅

🍎 iPhone / iPad (iOS)

  • Открой Happ -> Перейди в Profiles / Subscriptions
  • Нажми Add -> Выбери Import from URL
  • Вставь ссылку подписки и подтверди добавление профиля
  • Разреши VPN в системном окне iOS (Первый раз iOS попросит разрешение — это нормально) ⚠️
  • Включи VPN в приложении

💻 Компьютер (Windows / macOS / Linux)

  • Запусти Happ -> Открой Profiles / Subscriptions
  • Нажми Add -> Вставь ссылку подписки и сохрани
  • Выбери сервер (если нужно) и нажми Connect

📺 Android TV

  • Запусти Happ -> Зайди в Subscriptions / Profiles
  • Нажми Add -> Выбери From URL
  • Вставь ссылку (если неудобно вводить с пульта, используй Google Keyboard на телефоне или скопируй заранее)
  • Сохрани и включи VPN

🔁 Если подписка не работает:

  • Нажми Обновить подписку / Update 🔄
  • Удали подписку и добавь ее заново по ссылке
  • Перезапусти приложение
