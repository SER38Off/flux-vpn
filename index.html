SNI Bypass — маскирует VPN-трафик под обычный HTTPS. Провайдер видит запрос к легальному сайту (напр. cloudflare.com), а не к VPN-серверу.

XTLS-Reality — копирует TLS-отпечаток настоящего сайта. Невозможно отличить от легального HTTPS даже при глубоком анализе.

CIDR Routing — только заблокированные IP идут через VPN. Скорость не падает для разблокированных сайтов.
  • Выберите конфиг с фильтром 🔐 SNI/Reality в каталоге.Choose a config with the 🔐 SNI/Reality filter.
  • В Happ после импорта: Settings → Routing → «Только заблокированные» — включить белый список РКН/ЦБРФ.In Happ after import: Settings → Routing → «Blocked only» to enable RU whitelist mode.
  • Для Reality: ищите конфиги с тегом 🔐 XTLS-Reality — они обходят даже усиленный DPI.For Reality: look for 🔐 XTLS-Reality tagged configs — they bypass even deep DPI.
  • Если конфиг не работает — нажмите ⚡ Speed-чек чтобы проверить доступность URL.If a config fails — click ⚡ Speed-check to verify the URL is reachable.
